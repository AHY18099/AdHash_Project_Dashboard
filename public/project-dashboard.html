What does "Run All Tests" do?

The "Run All Tests" button triggers real-time automated testing across all your projects and platforms.

📊 What Gets Tested:

  • 📱 Mobile Apps - Verifies app availability on Play Store and App Store
  • 🖥️ Servers - Checks server health and response status
  • 🔒 SSL Certificates - Monitors certificate expiry dates
  • 🌐 Domains - Tracks domain expiration dates
  • ⚡ API Endpoints - Tests API availability and response times

⏱️ How It Works:

  • Tests run in the background (takes 2-5 minutes)
  • Dashboard updates automatically when tests complete
  • Real-time data is fetched from live sources
  • Results are saved and displayed immediately
📌 Note: The current dashboard shows cached results from the last test run. Click "Run All Tests" to fetch fresh, real-time data from all platforms and update the dashboard with the latest status.
